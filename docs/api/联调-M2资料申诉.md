# M2 账号资料与申诉联调记录

> 维护方式：前后端共同维护。状态：⬜ 待测 / ✅ 通过 / ❌ 失败
> 接口契约：`docs/api/02-account.md`；错误码：`docs/api/README.md`
> 覆盖接口：#45/#46 申诉、#76/#77 个人资料、#107-110 企业资料

## 一、环境信息

| 项 | 值 |
|---|---|
| 服务地址 | http://127.0.0.1:8888 |
| 数据库 | 127.0.0.1:3306（gva 库，ms_* 表） |
| Redis | 127.0.0.1:6379（DB 0） |
| 重启命令 | 停旧进程 → `cd server && go run main.go` |
| 取验证码 | mock 验证码存 Redis `hrc:sms:code:register:<mobile>`（无 redis-cli 时可用 `GET` 命令直读） |

## 二、测试前置

1. 获取会员 token：`POST /auth/sms-code`（type=register）→ 从 Redis 取 6 位码 → `POST /auth/login/sms`（未注册自动注册）拿 `token`。
2. 鉴权接口 Header：`Authorization: Bearer <token>`。
3. 测试用手机号：个人 `13900001111`、企业A `13900004444`、企业B `13900005555`、申诉 `13900003333`。
