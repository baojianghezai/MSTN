## 二、测试前置（必读）

1. **验证码获取**：一期不接短信网关，验证码打印在**服务端控制台/日志**（`sms code sent (mock) ... code:XXXXXX`）。测试时先调 sms-code 接口，再去日志取码。
2. **登录 token**：login/register 成功后响应里带 `token`，后续鉴权接口在 Header 加 `Authorization: Bearer <token>`。
3. **状态码约定**：业务失败 HTTP 200 + 业务 code（见 docs/api/README.md 错误码总表）；未登录 401。
4. 测试用手机号建议固定几个：`13306487850`（已有账号）、`13800138000` 等。
